# Sprintopoly

Retrospectiva Scrum multijugador para 5 personas.

## Publicar en GitHub Pages
1. Sube `index.html`, `styles.css` y `app.js` a la raíz del repositorio.
2. En GitHub: Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: `main`, carpeta `/ (root)` → Save.
5. Abre `https://TatianaMJS.github.io/sprintopoly/`.

## Importante
El proyecto usa Firebase Realtime Database. Antes de usarlo fuera de la prueba, reemplaza las reglas temporales de modo de prueba por reglas seguras.
